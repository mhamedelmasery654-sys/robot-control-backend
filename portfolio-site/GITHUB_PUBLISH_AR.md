# نشر الموقع على GitHub Pages

الموقع جاهز للنشر كصفحة ثابتة؛ لا يحتاج إلى خطوة بناء. استخدم مستودعًا عامًا مملوكًا لحساب `khaledElmasery`:

1. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بحيث يكون `index.html` في الجذر.
2. من إعدادات المستودع افتح **Pages** واختر النشر من الفرع `main` ومجلد `/ (root)`.
3. افتح رابط Pages الذي يعرضه GitHub. المسارات النسبية للصور والنماذج تعمل ضمن رابط المستودع.

ملف `.nojekyll` موجود لتقديم ملفات الأصول مباشرة. احتفظ بالملفات الأصلية داخل `public/` عند النشر كي تعمل معاينة GLB وروابط التنزيل.
