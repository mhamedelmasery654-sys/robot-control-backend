# معرض خالد المصري

موقع ثابت ثنائي اللغة (الإنجليزية والعربية) يعرض المشاريع مباشرة بعد الواجهة، ثم التعريف والمهارات والتعليم والخدمات والتواصل. عنوان الواجهة يبرز Backend Developer وEmbedded Systems Engineer وElectrical Engineer، ويستبدل الكتابة المخبوزة داخل الصورة المرجعية بنص حي مستند إلى السيرة والمشروعات.

## فتح الموقع

1. فك ضغط `khaled-portfolio-site-final.zip` إذا كنت تستخدم الحزمة.
2. شغّل `Open-Portfolio.ps1` من مجلد الموقع. سيبدأ خادمًا محليًا صغيرًا ويعرض الصفحة في المتصفح.
3. يمكن أيضًا تشغيل `python -m http.server 4173` داخل هذا المجلد وفتح `http://localhost:4173`.

يحتاج عارض GLB إلى فتح الموقع عبر خادم محلي أو استضافة ويب. فتح `index.html` بالنقر المزدوج قد يمنع المتصفح من تحميل وحدات JavaScript المحلية.

## النشر

خطوات النشر على GitHub Pages موجودة في `GITHUB_PUBLISH_AR.md`.

## الحركة والتفاعل

- روبوت حقيقي من ملف GLB يتحرك ببطء، ويمكن تدويره بالسحب وتقريبه بعجلة الفأرة وإيقاف حركته.
- عارض يد التحكم ثلاثي الأبعاد، مع حركة كاميرا وإضاءة تفاعلية.
- شرارات وخطوط طاقة ومؤشرات حية، ومسح ضوئي للشاشات.
- انتقالات ظهور أثناء التمرير، تمييز رابط القسم الحالي، شريط تقدم، وحركات دقيقة للبطاقات والخط الزمني.
- زر للتبديل بين الإنجليزية والعربية؛ إعداد الجهاز لتقليل الحركة يخفف المؤثرات.

## ملاحظات المحتوى

- النموذج EV-036 تصوري، وغير مقياسي، ولا يمثل رسومات تنفيذ أو تصنيع.
- نموذج الروبوت ثلاثي الأبعاد يوضح الشكل فقط؛ لا يدعي الموقع اكتمال التحقق من الحركة الفيزيائية أو تحكم ESP32 عبر Bluetooth.
- قبل نشر وسائط المصنع على الإنترنت، راجع الإذن ونسبة المساهمة. مكتبة الأصول الكاملة منفصلة، وبها وسوم تميّز الأعمال والمراجع والأرشيف.
- بيانات الموقع صيغت من السيرة والملفات المتوفرة. راجع النص النهائي قبل نشر الرابط للجمهور.

## التقنية

- HTML وCSS وJavaScript modules.
- Three.js `0.186.1` و`GLTFLoader` محليان داخل `public/vendor/`.
- لا يحتاج الموقع إلى خطوة بناء أو تثبيت حزم.
