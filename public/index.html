EVENTS & RESULTS ONLY

Standalone logging service

This service stores authenticated control-session events and validated command results. It does not send commands to a robot.

API PROCESSChecking…GET /api/v1/health/live
DATABASESChecking…PostgreSQL + MongoDB
REAL-TIME INGESTWebSocket/api/v1/ws

Connection workflow

  1. Create or sign in to an operator account.
  2. Open a control session and retain its ID.
  3. Post validated events through REST or the authenticated WebSocket.

Audio bytes, speech transcripts, passwords, and authentication tokens are not stored in event records.

API documentation: OpenAPI spec · Postman collection is in the project folder.
